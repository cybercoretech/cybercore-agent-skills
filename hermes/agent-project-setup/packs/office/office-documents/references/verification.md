# Rendering and Checking Output

A document is checked when you have looked at it, page by page or slide by slide.

## Render to images

```sh
# Office file to PDF (LibreOffice, local, headless)
soffice --headless --convert-to pdf --outdir out/render out/report.docx

# PDF pages to PNG images (poppler)
pdftoppm -png -r 80 out/render/report.pdf out/render/page
```

Then open the images and look at each one. Rendering through LibreOffice is close to, but not identical with, Microsoft Office; mention that when exact fidelity matters.

## What to look for

| Format | Check |
|---|---|
| All | Text fits; no overflow off the page or slide; fonts render (no fallback boxes); images present and sharp; page or slide count as expected |
| Word | Headings use heading styles; numbering continues correctly; tables do not split awkwardly; headers, footers and page numbers right; no leftover placeholders |
| Excel | Formulas intact (open with formulas, not values); no error values after recalculation; totals match the source; number and date formats correct; print area sensible if it will be printed |
| PowerPoint | Text inside placeholders; consistent layouts; readable font sizes at presentation distance; speaker notes where needed |
| PDF | Page order and rotation; text selectable (not an image) when produced from a document; bookmarks or headings carried over; forms fillable if they should be |

## Content checks with scripts

```sh
pdftotext -layout out/render/report.pdf - | grep -n "{{"        # leftover placeholders
pdftotext -layout out/render/report.pdf - | grep -c "Total"     # expected labels present
```

## Before sharing

- Document properties: author, company, title (set a meaningful title; clear personal names if requested). Files generated by libraries often carry the library's name as author (python-docx's default template uses "python-docx").
- Comments, tracked changes, hidden sheets, hidden slides, speaker notes: keep or remove as the user wants (never remove revision history from legal documents without approval)
- Embedded file paths and links to internal systems
- File size: compress large images if the document will be emailed

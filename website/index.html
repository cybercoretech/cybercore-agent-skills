Deployment Center

Clone once, then one command per agent

  1. Clone the repository anywhere: 
    git clone https://github.com/cybercoretech/cybercore-agent-skills.git
  2. Open a terminal in the root of the project you want to configure.
  3. Run your agent's installer below, replacing /path/to/cybercore-agent-skills with your clone.

Options: --with omarchy adds the opt-in Omarchy pack, --list-packs lists packs, --help shows usage. Existing files are backed up before they are replaced.
